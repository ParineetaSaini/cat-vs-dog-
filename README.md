# 🐶🐱 Dog vs Cat Image Classification

A deep learning computer vision project that classifies an image as either a dog or a cat using a CNN model.

## Features
- Binary image classification
- Image resizing and preprocessing
- CNN-based feature extraction
- Prediction on new images
- Evaluation using accuracy, precision, recall, and F1-score

## Tech Stack
Python, TensorFlow, Keras, NumPy, Matplotlib, Pillow

## Dataset
[Kaggle Dogs vs. Cats Dataset](https://www.kaggle.com/c/dogs-vs-cats/data)

## Installation
```bash
pip install tensorflow numpy matplotlib pillow
```

## How It Works
Input Image → Preprocessing → CNN → Dog or Cat

Run your training notebook or prediction script after configuring the dataset and model paths. Apply exactly the same preprocessing used during training.
